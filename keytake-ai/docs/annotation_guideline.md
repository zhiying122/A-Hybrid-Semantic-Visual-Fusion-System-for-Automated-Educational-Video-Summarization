# KeyTake AI 重點片段標註準則

本文件供兩位（含以上）標註者建立 Ground Truth 使用。目標是讓不同標註者
對「哪些片段是教學重點」的判斷盡量一致，以取得可信的 Cohen's Kappa。

---

## 一、標註目標

對教學影片逐字稿的每一個片段，以 **Likert 1~5 分** 評估其「教學重要性」：
若你要向缺席的同學說明這堂課，這段內容值不值得保留？

| 分數 | 意義 |
|------|------|
| 5 | 非常重要：核心概念、關鍵推導、必考重點，刪掉會看不懂 |
| 4 | 重要：重要說明或例題，建議保留 |
| 3 | 普通：有幫助但非必要 |
| 2 | 次要：補充、閒聊性質偏多 |
| 1 | 不重要：寒暄、點名、行政公告、口誤、離題 |

**列入 Ground Truth 的條件：兩位標註者「都」給 ≥ 4 分。**

---

## 二、判斷原則（讓兩人一致的關鍵）

### 應給高分（4~5）的內容
- **概念定義**：解釋核心術語、下定義（「所謂的極限就是…」）
- **公式推導 / 證明**：一步步演算、推導過程、定理證明
- **關鍵例題**：示範如何套用概念解題
- **重點總結**：整理、歸納、強調「這裡很重要 / 會考」
- **因果與原理**：解釋「為什麼」而非只是「是什麼」

### 應給低分（1~2）的內容
- **寒暄與行政**：問好、點名、作業繳交、教室事務
- **過渡語**：「那我們接下來看」「等一下」「好」單獨成句
- **離題閒聊**：與課程主題無關的談話
- **口誤 / 重複 / 靜默**：語音辨識殘渣、無意義填充詞

### 灰色地帶的一致化規則
- 一句話同時含重點與過渡 → 依「主要內容」評分
- 例題的鋪陳（讀題）與求解 → 求解過程給高分，單純讀題給中分
- 不確定時，先各自獨立評分，事後於 merge 階段再討論歧異片段

---

## 三、操作流程

```bash
cd keytake-ai

# 1. 產生逐字稿（每部影片一次）
python tools/export_transcript.py --video data/videos/<影片檔> --output data/annotations/

# 2. 兩位標註者各自獨立評分（不要互看）
python tools/annotator.py annotate data/annotations/transcript_<vid>.json --annotator A
python tools/annotator.py annotate data/annotations/transcript_<vid>.json --annotator B

# 3. 合併並計算 Cohen's Kappa，產生 Ground Truth
python tools/annotator.py merge annotations/annotator_A.json annotations/annotator_B.json \
    --output data/annotations/gt_<vid>.json
```

## 四、一致性標準（Cohen's Kappa）

| Kappa 範圍 | 一致性 | 處理方式 |
|-----------|--------|----------|
| ≥ 0.80 | 幾乎完全一致 | 直接採用 |
| 0.60 ~ 0.80 | 良好 | 可採用，論文報告數值 |
| 0.40 ~ 0.60 | 中等 | 討論歧異片段後重標一次 |
| < 0.40 | 不足 | 重新對齊本準則，必要時請指導老師仲裁 |

論文中須誠實報告 Kappa 值與標註者人數。若僅單人標註，須明確標示為
「single-annotator pilot（單人標註可行性驗證）」，不可宣稱為最終效能。

---

## 五、注意事項

- 兩位標註者務必使用**同一份逐字稿**，否則片段無法對齊。
- 評分時**獨立作業**，避免互相影響，否則 Kappa 會虛高。
- 建議每部影片標註前，兩人先一起看前 5 段對齊標準，再分開作業。
